# 🐼 Python Data Analysis with Pandas | Data Technician Bootcamp

## 🚀 Overview

This project was completed during a Data Technician Bootcamp and demonstrates the use of Python and the Pandas library to explore, clean, manipulate, and analyse data.

Using Pandas, I worked with structured datasets to perform filtering, data transformation, calculations, and exploratory analysis. The project focused on developing practical data analysis skills used within business environments to prepare data, answer analytical questions, and generate meaningful insights.

In addition, I used Python to manipulate DataFrames, create new columns, transform data types, and perform calculations that support data-driven decision-making.
